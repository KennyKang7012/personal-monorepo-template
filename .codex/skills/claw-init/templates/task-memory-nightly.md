# 每晚記憶整理任務規格

為 {{AI_NAME}} 整理 {{USER_ADDRESS}} 已授權保存的每日工作摘要。預計時間：{{MEMORY_TIME_HUMAN}}；時區：{{TIMEZONE}}。這是任務規格，尚未啟用自動化。

## 手動與排程共用 prompt

在已核准的工作區執行，先讀 `AGENTS.md`、`WORKSPACE.md` 與 `agents/memory-keeper.md`，依指定時區判定本次日期。

僅使用已核准保存且可取得的當日工作來源，不掃描全域聊天紀錄。先讀現有每日記憶與索引，將有證據的新事項去重後合併至 `memory/YYYY-MM-DD.md`，重大決定以相對連結補入 `MEMORY.md`。不覆寫其他執行者的內容，不記敏感原文。

完成後驗證新增內容與索引連結，在 `logs/` 留不含敏感資料的執行摘要。可寫入範圍僅限當日記憶、必要的長期索引與本次 log；不更動規則、設定、排程或外部服務。不假定可用 sub-agent；主 agent 可依角色說明完成。

來源不足時回報「未取得當日紀錄」與缺漏，不虛構活動。無新事項時不重複寫記憶；預設只在新增重要事項、失敗或需要使用者處理時，透過 Codex 的結果介面通知。{{MAIN_CHANNEL}} 若是外部介面，須另外確認連接能力與傳送授權。

## 啟用前檢查

1. 確認工作目錄的絕對路徑、時間、時區與保存授權，將這些內容寫入可獨立執行的 prompt。
2. 先手動測試，檢查產物與寫入範圍；保留實際證據。
3. 使用者另行要求啟用後，探索當前自動化工具 schema，核對既有排程以避免重複，只建立／更新指定項目。
4. 本地執行確認機器、app 與工作區可用；若選 worktree，確認輸入已存在且有核准的輸出回收方式，不能假設寫入會同步至原工作目錄。
5. 記錄實際 automation ID、查核時間及設定狀態，排程執行與無人值守驗收另行記錄。無工具時保持手動規格，不採用刪除重建管家。
